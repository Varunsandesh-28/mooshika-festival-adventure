Create a polished original 3D-style endless runner browser game called:

🐭 MOOSHIKA: MODAK RUN
"Ganesha's Festival Adventure"

IMPORTANT:
This should be an ORIGINAL endless-runner game inspired by the general genre of games like Temple Run, but do NOT copy Temple Run's characters, artwork, maps, logos, sounds, UI, or other copyrighted assets.

The main character is Mooshika, a cute original mouse character.

GAMEPLAY:
Mooshika automatically runs forward through a beautiful Ganesh Chaturthi festival environment.

The player controls Mooshika with:

LEFT ARROW / A = move left
RIGHT ARROW / D = move right
UP ARROW / W = jump
DOWN ARROW / S = slide

Also add mobile touch/swipe controls.

OBJECTIVE:
Run as far as possible, collect modaks and festival coins, avoid obstacles, and achieve the highest score.
